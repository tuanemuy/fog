### 指摘（不具合ではない）

- (a) `SearchIndexPort` は `query(query): SearchPage` の同期 1 メソッド、`domain/search/ports/searchIndexPort.ts`。`UserDataUnitOfWorkContext.searchIndex`（読み取り専用の JSDoc）に載り、書き込みポートは無い — 更新は `memoRepository` / `documentRepository` の `save` 内の `searchProjection` のまま。spec/domains/search.md「書き込み側はポートではない」どおり
- (b) MATCH: `phraseOf` が `"` を `""` に倍化して全体を 1 フレーズに引用し、バインド変数で渡す（`search_fts MATCH ?`）。フレーズ内では `AND` / `OR` / `NOT` / `*` / `^` は解釈されない（A-5 の `<script>…` / 絵文字が 0 件で例外なし、`FOGSEARCH` は trigram の大小無視）。3 文字未満は `instr(e.title, ?) > 0 OR instr(e.body, ?) > 0` — spec/database L868 の述語形そのまま、`LIKE` / `GLOB` を使わない、`LIMIT 500`。絞り込み述語は「配下 doc」or「active なドキュメントの出典メモ」（`EXISTS` + `d.status = 'active'`）
