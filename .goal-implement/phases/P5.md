## 実装

採用 runtime を Node.js + libSQL に統一した。AWS/GCP/Cloudflare/Durable Objects の entry、worker、infra、設定、依存、deploy scripts、公開 Todo サンプルと専用永続 adapter を削除した。削除対象は [一覧](P5-removals.json)、最終削除状態は [対象 manifest](P5-target-hashes.json)。generic clock/ID/logger/UoW/outbox/idempotency の ports、共通 error/lib は必要な構造として残した。既存 DB の旧 table、spec、モック、ユーザー `.env`、管理証跡は保持した。新規 migration は fog の table だけを作る。

Node DI は実際の fog 配線だけを持つ。APP_URL を HTTP(S) origin、PORT を1〜65535で検査する。クラウド URL/auth token の配線を維持し、WAL/busy timeout は file 接続だけに適用する。`pnpm db:migrate` は再実行可能で、起動前にも実行できる。

production launcher は通常の Node.js から build を読み込み、公開静的 asset を配信する。MIME/HEAD/cache を扱い、dotfile、traversal、外部 symlink を拒否する。macOS の `/tmp` realpath を扱う検査も追加した。`GET /healthz` は DB readiness を返す。SIGINT/TERM は HTTP と稼働中 worker を drain してから DB を閉じる。不要な Todo relay は起動しない。

README、環境変数例、Node 運用、test、実装例、CLAUDE の参照を現在の製品へ更新した。Node 用 CI と `infra/node/fog.service` を準備した。systemd はこの macOS 環境へ設置していない。依存373個を除去し、pnpm の frozen install を確認した。過去 install metadata 向けの `allowBuilds.workerd: false` は残るが、workerd package、runtime、lockfile dependency は残していない。
