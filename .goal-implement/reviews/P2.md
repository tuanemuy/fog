## SSR と presentation のレビュー

pnpm patch は deferred serialization が HTML transform 開始前に完了したときの未注入 script queue を検査し、script が残る応答を注入経路へ通す。render 終了時にも同期 flush する。source/ESM/CJS と declaration に同じ修正があり、version override・lock の patch 登録と一致する。RSC/Deferred/Suspense による streaming は維持している。回帰テストは transform 前/後の settlement の双方を扱い、初期 HTML を先に受け取れること、resolved content と e() が body の閉じタグ前へ出ることを確認する。直接 history と直接 document の UI、client navigation も独立確認した。

timeline の一覧 owner は追加取得済みメモの編集結果を受け取り keyword を再評価する。search の変更は TimelineBoard の key を変えてページ状態を初期化する。memo/document の rollback は失敗時も invalidate するため、古い expectedVersion のまま失敗し続けない。mutation の pending、楽観表示、入力保持、競合確認と owner 原子性に P2 範囲の受け入れ阻害指摘はない。
