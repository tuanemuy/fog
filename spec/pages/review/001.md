# 画面構成レビュー 001

対象: spec/pages/index.md
方法: 全シナリオ（S-AC / S-TL / S-DT / S-SE / S-TR / S-ST / S-AI）と ADR-001〜003 を画面定義にマッピングして検証。

画面一覧としてはシナリオを実現する画面が揃っており、大きな漏れはない。以下は対応が必要な問題点。

## 1. P-04 タイムライン: メモ編集のバリデーション状態が欠落（S-TL-04 異常系）

- **対象画面**: P-04
- **問題**: S-TL-04 の異常系「変更せずに保存した場合、新しいリビジョンは積まれない」「空文字に書き換えて保存することはできない」が P-04 に記載されていない。投稿時の空文字不可はあるが、インライン編集時の制約が未定義。ドキュメント側（P-09）は同等の制約を明記しており非対称。
- **修正提案**: P-04 の機能または状態に、メモ編集時の「空文字保存不可」「変更なしなら新リビジョンを積まない」を追記する。

## 2. P-04 タイムライン: 出典先ドキュメントのハードデリート時の挙動が未記載（S-TL-07 エッジ / ADR-003）

- **対象画面**: P-04
- **問題**: 「→ ドキュメントX」導線について、参照先ソフトデリート時の表示は定義されているが、ハードデリート時に「出典リンク自体が消え、導線は表示されない」（S-TL-07 / ADR-003）が書かれていない。P-08 側の「元になったメモ」ではハードデリート時の非表示を明記しており、片側だけ欠けている。
- **修正提案**: P-04 の出典導線の記述に「参照先がハードデリート済みなら導線自体を表示しない（ADR-003）」を追記する。

## 3. P-04 タイムライン: 他画面からの「該当位置へ遷移」の受け側機能が未定義

- **対象画面**: P-04（関連: P-07, P-08, P-11, P-12）
- **問題**: P-07 の関連メモ、P-08 の「元になったメモ」、P-11 の検索結果（メモ）はいずれも「タイムラインの該当位置へ」遷移すると定義されているが、P-04 側に「指定メモの位置を表示する」機能・状態（対象メモがゴミ箱に移動済み・ハードデリート済みで見つからない場合を含む）が定義されていない。遷移先としての責務が宙に浮いている。
- **修正提案**: P-04 の機能に「指定メモ位置の表示（他画面からの遷移の受け口）」を追加し、対象メモが存在しない場合の状態（案内表示等）を定義する。

## 4. P-05 / P-10 履歴画面: 対象不在の状態が欠落

- **対象画面**: P-05, P-10
- **問題**: `/memos/:id/history` `/documents/:id/history` はURL直アクセス可能だが、対象のメモ／ドキュメントが不在（ソフトデリート済み・ID不正）の場合の状態が定義されていない。P-07・P-08 には「見つからない」状態があり、履歴画面だけ考慮漏れ。
- **修正提案**: P-05・P-10 に「対象不在: 『見つからない』表示＋戻り導線」の状態を追加する。

## 5. P-09 ドキュメント編集: 読み込み中・対象不在の状態が欠落

- **対象画面**: P-09
- **問題**: 状態が入力エラー・競合警告・保存中・保存失敗のみで、(a) 編集モードで既存ドキュメントを読み込む間の「読み込み中」、(b) 編集対象ドキュメントが不在の場合、(c) 新規モード（/topics/:id/documents/new）で作成先トピックが不在（削除済み・ID不正）の場合、の状態がない。(c) は S-AI-03 異常系（削除済みトピックへの作成はエラー）の人間UI側の対応でもある。
- **修正提案**: P-09 に「読み込み中」「対象ドキュメント不在」「作成先トピック不在」の状態を追加する。

## 6. 画面一覧表: S-AC-04（ログアウト）のマッピング漏れ

- **対象画面**: 画面一覧表（P-13）
- **問題**: S-AC-04（ログアウト）がどの画面の「主なシナリオ」列にも現れない。P-13 の機能にはログアウトがあるため機能漏れではないが、シナリオ→画面の対応表として欠落しており、カバレッジ確認の用をなさない。
- **修正提案**: P-13 の主なシナリオに S-AC-04 を追加する。
