# 画面構成レビュー 002

対象: spec/pages/index.md
方法: spec/requirements.md・spec/idea.md・spec/adr/・spec/scenario/ 全シナリオとのゼロベース照合

全シナリオ（正常系・異常系・エッジケース）と画面一覧・機能・状態を突き合わせた。画面の漏れはなく、状態定義（読み込み中・空・エラー・不在フォールバック）も概ね揃っている。対応が必要な問題は以下の2件。

## 指摘事項

### 1. P-07 関連メモ一覧における削除済み出典メモの扱いが未定義

- 出典メモがソフトデリートされた場合の表示は、P-08（ドキュメント）の「元になったメモ」一覧では定義済み（「削除済みのメモ」表示・遷移不可）だが、P-07（トピック詳細）の関連メモ一覧では未定義。
- 関連メモは「配下ドキュメントの出典になっているメモ」の集合であり、同じケースが必ず到達可能。一覧に表示するのか（「削除済みのメモ」として残すのか）、除外するのかを P-08 と整合する形で定義すること。ハードデリート時は ADR-003 により出典リンクごと消えるため関連メモからも消える、という点も明記が望ましい。

### 2. P-11 検索のトピック絞り込み選択肢に完了済みトピックを含むかが未定義

- S-SE-01 / requirements 4.4 により、完了済み（アーカイブ）トピック配下のドキュメントは検索にヒットする。したがって P-11 のトピック絞り込み UI で完了済みトピックが選択できないと、「完了済みトピックに絞って検索する」経路が存在しなくなり、シナリオの保証と矛盾する。
- トピック選択肢に完了済みトピックを含む（例: 進行中と区別して表示する）ことを P-11 の機能定義に明記すること。

## 補足（対応不要と判断した点）

- P-02 の SSO 中断・失敗状態は「初回SSOログインと同一フロー」の参照で P-01 の定義が適用されると読めるため、指摘対象としない。
- P-03 の再設定フォームのURL（トークン付きリンク）はパス想定の粒度の問題であり、実装詳細として指摘対象外。
