# 画面構成

レスポンシブWeb（PC・スマホ両対応）。すべての利用シナリオ（spec/scenario/）を実現する画面を定義する。

## 共通レイアウト

- 認証後の画面はグローバルナビゲーション（タイムライン / トピック / 検索 / ゴミ箱 / 設定）を共有する。PCではサイドバー、モバイルでは下部タブ相当
- 未ログインで保護画面にアクセスした場合はログイン画面へリダイレクトし、ログイン後に元のURLへ戻る（S-AC-03）
- 通信エラーは共通のエラー表示（リトライ導線付き）で扱う

## P-01 ログイン

- **目的**: 本人確認を行い、保護された画面への入口となる
- **機能**:
  - メールアドレス＋パスワードでログイン
  - SSO（Google / Apple 等）で続行
  - アカウント登録（P-02）・パスワードリセット（P-03）への導線
- **状態**:
  - 初期: 入力フォーム表示
  - 送信中: ボタン無効＋進行表示
  - 認証エラー: 「メールアドレスまたはパスワードが正しくない」を表示し再入力可
  - SSO中断: プロバイダ側キャンセルで初期状態に戻る（エラー扱いしない）
  - 成功: タイムライン（またはリダイレクト元URL）へ遷移

## P-02 アカウント登録

- **目的**: 新規ユーザーのアカウント作成
- **前提**: 登録時にメールアドレスの所有確認（verification）は行わない。所有の唯一の証明はパスワードリセット経路であり、登録直後の画面文言もこの前提の上に立つ
- **機能**:
  - メールアドレス＋パスワードで登録
  - SSOで登録（初回SSOログインと同一フロー）
  - ログイン（P-01）への導線
- **状態**:
  - 初期: 入力フォーム表示
  - 入力エラー: メール形式不正・パスワード要件未満を項目ごとに表示
  - 重複エラー: 登録済みメールの場合は「このメールアドレスは既に登録されています」を表示し、ログインへの導線を出す
  - 送信中 → 成功: タイムラインへ遷移

## P-03 パスワードリセット

- **目的**: パスワードを忘れたユーザーの回復
- **機能**:
  - メールアドレスを入力してリセットメールを依頼。**依頼フォームは誰にでも出す**（登録済み / 未登録 / SSO 専用 / スロットル中のいずれでも応答が同一であるため、フォームの出し分けで登録の有無を漏らさない）
  - メール内リンクから新パスワードを設定
  - リセット完了画面に必須の導線を2つ置く（下記）
- **完了画面の認証文脈**: 新しいパスワードの設定が完走した時点で**新しいセッションが確立される**ので、完了画面は**ログイン済みの画面**である。旧セッション（侵害者が握っていたものを含む）はこの時点で失効しており、下の必須導線2つはこの新しいセッションの上で動く。**再ログインを挟まない** — 挟むと、リセットの直後に「覚えの無いものをその場で解除させる」という導線の目的が果たせない
- **完了画面の必須導線**: 次の2つを**同じ画面に**まとめて提示し、覚えの無いものをその場で解除させる。侵害からの復旧手順の一部であり、任意の追加導線ではない
  - **クレデンシャル一覧** — 保有クレデンシャルを一覧し、覚えの無い SSO 連携を解除できる
  - **AI クライアント接続一覧と「すべて失効」** — 自動失効が切るのは前回のリセット完了以降に作られた接続だけなので、それより前に持ち込まれた接続は利用者の判断で切る
- **状態**:
  - 依頼フォーム → 送信済み: 「登録されていれば送信された」旨を表示（登録有無は明かさない）
  - 再設定フォーム: 新パスワード入力。要件未満はエラー表示
  - リンク期限切れ: その旨を表示し、依頼フォームへの導線を出す
  - 成功: ログイン済みの状態で上の必須導線2つを提示し、確認を終えたらそのままアプリ（タイムライン）へ進める

## P-04 タイムライン

- **目的**: メモの投稿と時系列閲覧。アプリのホーム
- **機能**:
  - メモ投稿欄（常設）。空文字は投稿不可
  - メモを新しい順に日付見出しでグルーピング表示。Markdown軽装飾を整形表示
  - 無限スクロールで過去分を読み込み
  - キーワード絞り込み・絞り込み解除
  - 日付指定でその位置へジャンプ（該当日にメモがなければ前後の最も近い位置）
  - 各メモの操作メニュー: 編集（インライン）・履歴（P-05へ）・削除（確認ダイアログ→ソフトデリート）
  - メモ編集: 空文字への書き換えは保存不可。変更がなければリビジョンを積まない。開始後に他者（AI）の編集があった場合は警告を表示してから保存
  - 出典になっているメモに「→ ドキュメントX」導線を表示（複数可）。タップで P-08 へ。参照先がソフトデリート済みなら「削除済みのドキュメント」表示で遷移不可。ハードデリート済みなら導線自体を表示しない
  - 指定メモ位置の表示: 他画面（P-05/P-07/P-08/P-11）から「タイムラインの該当位置へ」遷移された場合、該当メモの位置までスクロールしハイライト表示する
- **状態**:
  - 読み込み中: スケルトン表示
  - 空: 最初のメモを促す案内
  - 絞り込み結果0件: 「見つからなかった」表示＋解除導線
  - 投稿失敗: 入力内容を保持したままエラー＋リトライ
  - 追加読み込み中: 末尾にローディング表示
  - 指定メモ不在（削除済み・ID不正で位置指定遷移された場合）: 「見つからない」旨を通知し通常のタイムライン表示にフォールバック

## P-05 メモ履歴

- **目的**: メモのリビジョン確認とロールバック
- **機能**:
  - リビジョン一覧（誰が・いつ。AIクライアントはクライアント名で表示）。**古い版から昇順に並べる**
  - 任意二点の選択による差分表示。**1回目に選んだ版が比較元、2回目が比較先**
  - **比較元の版**の「この内容に戻す」（同内容の新リビジョンを積む。確認あり）。上から順に二点を選ぶと古いほうが比較元になり、そのまま戻す対象になる
- **状態**:
  - 読み込み中 → 一覧表示
  - リビジョンが1件のみ: 差分・ロールバック操作を非表示
  - 対象メモ不在（削除済み・ID不正）: 「見つからない」表示＋タイムラインへの導線
  - ロールバック成功: 最新リビジョンに反映されタイムラインへ戻る

## P-06 トピック一覧

- **目的**: 文脈（トピック）の俯瞰と入口
- **機能**:
  - 進行中トピックを説明文付きで一覧表示
  - 完了済みトピックを下部の「完了済み」セクションに畳んで表示（開閉可）
  - 新しいトピックの作成（名前必須・説明文任意）
  - トピック選択で P-07 へ
  - 長押し（PCは右クリック/メニュー）で削除（確認ダイアログ→配下ドキュメントごとソフトデリート）
- **状態**:
  - 読み込み中: スケルトン表示
  - 空: 案内表示＋作成導線
  - 作成フォームエラー: 名前空で作成不可
  - 完了済みセクション: 0件なら非表示

## P-07 トピック詳細

- **目的**: トピック配下のドキュメントと関連メモの閲覧、トピックの管理
- **機能**:
  - トピック名・説明文の表示と編集（名前空は不可）
  - 「完了にする」/「完了を解除」のワンアクション（「アーカイブ」という語は使わない）
  - 配下ドキュメントの一覧表示。選択で P-08 へ
  - 新しいドキュメントの作成（P-09 の新規モードへ）
  - 関連メモ一覧（配下ドキュメントの出典になっているメモ）。選択でタイムラインの該当位置へ。ソフトデリート済みのメモは「削除済みのメモ」表示で遷移不可（P-08 と同じ扱い）。ハードデリート済みは表示しない
  - 削除は操作メニューの別階層に配置（完了と並べない）。確認後、配下ごとソフトデリート
- **状態**:
  - 読み込み中 → 表示
  - 配下ドキュメント0件: ドキュメント作成への導線を表示
  - 関連メモ0件: セクションを控えめに表示（または非表示）
  - 編集フォームエラー: 名前空で保存不可
  - トピック不在（削除済み・ID不正）: 「見つからない」表示＋トピック一覧への導線

## P-08 ドキュメント

- **目的**: ドキュメントの閲覧と出典メモの確認
- **機能**:
  - 本文の整形表示（構造化テキスト）
  - 所属トピックへの導線
  - 「元になったメモ」一覧を本文と別領域に投稿日時付きで表示。選択でタイムラインの該当位置へ。出典メモがソフトデリート済みなら「削除済みのメモ」表示で遷移不可。ハードデリート済みなら項目自体を表示しない
  - 編集（P-09 へ）・履歴（P-10 へ）・削除（確認→ソフトデリート）
- **状態**:
  - 読み込み中 → 表示
  - 出典0件: 「元になったメモ」領域を非表示
  - ドキュメント不在（削除済み・ID不正）: 「見つからない」表示＋所属トピックまたはトピック一覧への導線

## P-09 ドキュメント編集

- **目的**: ドキュメントの新規作成・本文編集
- **機能**:
  - 新規: タイトル・本文の入力。出典メモの検索・選択による紐付け（任意）。作成先トピックは呼び出し元（P-07）で確定
  - 編集: タイトル・本文の変更。変更理由（一行サマリ）の入力欄（省略時は「手動編集」が記録される）
  - 保存で新リビジョンを積む（変更がなければ積まない）
- **状態**:
  - 読み込み中（編集モード）: 現在の内容を読み込むまでスケルトン表示
  - 対象不在: 編集対象のドキュメント、または作成先トピックが不在（削除済み・ID不正）の場合、「見つからない」表示＋トピック一覧への導線
  - 入力エラー: タイトル空で保存不可
  - 競合警告: 編集開始後に他者（AI）の編集があった場合、警告を表示。そのまま保存すると自分の内容が新リビジョンになる
  - 保存中 → 成功: P-08 へ戻る
  - 保存失敗: 入力内容を保持してエラー＋リトライ

## P-10 ドキュメント履歴

- **目的**: ドキュメントのリビジョン確認とロールバック
- **機能**:
  - リビジョン一覧（誰が・いつ・なぜ。AIクライアントはクライアント名＋変更理由で表示）
  - 任意二点の差分表示
  - 過去リビジョンへの「この内容に戻す」（確認あり。同内容の新リビジョンを積む）
- **状態**:
  - 読み込み中 → 一覧表示
  - リビジョン1件のみ: 差分・ロールバック操作を非表示
  - 対象ドキュメント不在（削除済み・ID不正）: 「見つからない」表示＋トピック一覧への導線
  - ロールバック成功: P-08 へ戻り最新内容が反映されている

## P-11 検索

- **目的**: メモ・ドキュメント横断の全文検索
- **機能**:
  - キーワード入力で検索実行（未入力では実行しない）
  - トピックによる絞り込みの指定・解除。絞り込みの選択肢には完了済みトピックも含む（完了済みの内容も検索対象のため）
  - 結果一覧: 種別（メモ/ドキュメント）・スニペット・タイムスタンプ・所属トピックを表示
  - 続きの読み込みは「もっと読む」で行い、ページ番号を指定する導線は持たない
  - 結果選択で、メモはタイムラインの該当位置、ドキュメントは P-08 へ
- **状態**:
  - 初期: 入力待ち（案内表示）
  - 検索中: ローディング表示
  - 結果0件: 「見つからなかった」表示
  - 結果あり: 一覧表示。ゴミ箱内は含まれず、完了済みトピックの内容は含まれる
  - 絞り込み対象のトピックが見つからない: 空結果ではなくその旨を表示し、絞り込みを解除しての再検索へ誘導する（選択肢は画面を開いた時点のスナップショットなので、別の場所でトピックがゴミ箱へ入ると到達する）

## P-12 ゴミ箱

- **目的**: ソフトデリート済み項目の確認・復元・完全削除
- **機能**:
  - 削除済み項目（メモ/ドキュメント/トピック）の一覧。削除日時と保持期限までの残り日数を表示
  - トピックとセット削除された配下ドキュメントは、セット関係が分かる表示
  - 復元: メモは元の位置へ、ドキュメントは元のトピックへ、トピックは配下ごと復元
    - 所属トピックもゴミ箱内の場合: セット復元の確認を挟む
    - 所属トピックがハードデリート済みの場合: 復元先トピックの選択（既存/新規作成）を求める
  - 完全に削除: 「履歴ごと消え、元に戻せない」確認 → ハードデリート。トピックはセットの配下も対象である旨を確認に含める
  - 空にする: 全件数を示す確認 → 全件ハードデリート
- **状態**:
  - 読み込み中 → 一覧表示
  - 空: 「ゴミ箱は空」表示。「空にする」は非活性
  - 操作中: 対象項目を操作不可に
  - 操作失敗: エラー＋リトライ

## P-13 設定

- **目的**: アカウント・AI接続・データ管理の各種設定
- **機能**:
  - 接続済みAIクライアント一覧（名前・接続日時・最終利用日時）と「接続を解除」（確認あり。解除後は操作できない）
  - ゴミ箱の保持期限の変更（既定30日。0以下等の範囲外は保存不可。既存のゴミ箱項目にも適用）
  - データエクスポート（Markdown等の可搬形式。生成中表示 → ダウンロード。ゴミ箱・履歴は含まない）
  - パスワード変更（現在のパスワード必須）。メールアドレスによるログイン手段がないアカウントには、パスワード変更フォームとリセット導線を表示しない
  - ログイン手段の一覧。外部アカウント連携は解除できるが、メールアドレスによるログイン手段と最後のログイン手段は解除できない
  - SSO 連携の追加（対応プロバイダで続行し、現在のアカウントに紐づける）。**この画面が、覚えの無い連携をリセット完了画面（P-03）で解除できる状態を作る唯一の入口である**
  - ログアウト
- **状態**:
  - 読み込み中 → 表示
  - AIクライアント0件: 接続方法の案内を表示
  - エクスポート生成中: 進行表示。完了でダウンロード可能
  - SSO 連携の追加が成立しない: 対象の主体が既に使われている（別のアカウント / 自分のアカウントを問わない）場合はその旨を表示し、クレデンシャル一覧は変わらない
  - パスワード変更の試行が制限されている: 「試行が制限されている」旨を明示する。**未認証のログイン経路（P-01）とは開示方針が反転する** — あちらはロックアウト中であることを応答から区別できないようにするが、認証済みのこの経路では隠さない
  - 各フォームの保存中・エラー・成功を項目ごとに表示

## P-14 AIクライアント認可

- **目的**: AIクライアントへのアクセス許可
- **機能**:
  - 要求元クライアント名と、許可される操作の一覧を表示（読み取り・書き込み。ハードデリート・ゴミ箱・履歴操作は含まれないことを明示）
  - 「許可する」→ クライアントへ戻り接続完了
  - 「拒否する」→ 接続不成立をクライアントへ通知
- **状態**:
  - 未ログイン: 先にログイン（P-01）を挟み、認可画面へ戻る
  - 不正リクエスト（改ざん・期限切れ）: 許可ボタンを出さずエラー表示
  - 処理中: ボタン無効化
