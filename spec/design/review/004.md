# デザインレビュー 004（/audit — アクセシビリティ・レスポンシブ）

対象: 全14画面。独立した2監査（主要7 / 補助7）の統合。

## 修正した問題

### コントラスト（WCAG AA）

1. **紫塗りボタンの白文字 3.4:1** — 全画面の主要 CTA。背景を `--color-primary-dark`（4.7:1）に、hover を `--color-primary-darker` に変更。tokens.md に Primary コントラスト規約を明文化
2. **白地上の紫テキスト 3.4:1** — テキストリンク・テキストボタンを `--color-primary-dark` に。本文中リンク（timeline）は常時下線も付与
3. **primary-lighter 上の紫文字 2.7〜3.9:1** — 選択チップ・`mark` ハイライトを `--color-primary-darker`（6.0:1）に
4. **淡色セマンティック背景上の文字 3.0〜3.8:1** — success/warning/error の `-dark` ペアをトークンに追加し、バナー・差分行・フィードバックに適用
5. **neutral-400 の操作系・見出しへの流用 2.7:1** — settings の h2 見出し、「または」区切り、「できないこと」、trash の保持期限説明、topics の開閉トグルを `--color-neutral-600` に

### フォームの機械可読性

6. label と input の `for`/`id` 関連付け欠落（認証4画面・settings・document-edit の全フォーム）
7. `autocomplete`（email / current-password / new-password）の全面欠落
8. エラーの `aria-invalid` / `aria-describedby` / `role="alert"` の欠落

### セマンティクス・キーボード

9. h1 欠落（12画面） — ヘッダータイトルを h1 化（見た目不変）
10. trash 確認ダイアログの `role="dialog"` / `aria-modal` / `aria-labelledby` 欠落
11. 閉状態のナビシート・オーバーレイが Tab 順序に残存 — `visibility: hidden` を追加
12. メニュー・開閉トグル・ポップオーバートリガーの `aria-expanded` / `aria-controls` 欠落
13. search の `.result-jump`（span に aria-label）を装飾扱い（`aria-hidden`）に整理
14. `.loading-more` に `role="status"`、差分表示に `aria-live="polite"`

### タッチターゲット

15. 行内アイコンボタン（jump / entry-menu / restore / delete / action-icon 等）と settings の小型ボタンが 20〜31px — `min-width/height: var(--tap-min)` + 負マージンで当たり判定 44px を確保

## 実装段階へ引き継ぐ事項（モックでは対応しない）

- 一覧の `ul/li` セマンティクス化（行構造の書き換えを伴うため、React コンポーネント実装時に対応）
- `<button>` 内のブロック要素（p / div）— 表示は問題ないが、実装時は行を `<a>`/`<div role="link">` + 内部アクションに分離
- ナビシート・ダイアログのフォーカストラップ / Escape クローズ / `inert`
- oauth の許可・拒否ボタンの POST form 化
- placeholder のコントラスト（慣例上許容。実装時はラベル併用で情報欠落なし）
- `--color-neutral-400`（2.7:1）自体の暗色化は不採用 — 用途を `--text-xs` メタ情報に限定する運用で対処（index.md に明記済み）

## 問題なしと確認された主要項目

- 375px で横スクロールなし（全14画面）、`prefers-reduced-motion` 全対応、ランドマーク（main/nav/header/aside）完備、アイコンボタンの `aria-label` 完備、`:focus-visible` リングほぼ完備、差分表示は +/− 記号併用で色非依存、`lang="ja"` / viewport 適切
