# デザインレビュー 002（/critique）

対象: 全14画面。独立した2レビュー（主要7画面 / 補助7画面）の統合。対応が必要な問題のみ記載。

## 重大

1. **topic-detail / document — `<button>` ネストによる行レイアウト崩壊**: `.doc-row` / `.origin-row`（button）内に `.jump` / `.o-jump` の button がネストされ、ジャンプアイコンが UA デフォルト描画で行の下に落ちている（001 の topics と同根）。行を `div` + `button.row-main` + アイコンボタンの構造に分離する。
2. **trash — 確認ダイアログの「完全に削除」が赤ベタ塗り**: 方針は「実行ボタンは `--color-error` の文字色で区別」。白地 + error 文字 + ヘアライン枠に変更。hover の直値 `oklch(0.45 0.19 27)` は `--color-error-dark` トークンへ。
3. **trash / document — error 色が常設 UI に浸透**: 全行の赤ゴミ箱アイコン・ヘッダーの赤削除アイコンを `--color-neutral-500` に。赤は確認ダイアログと逼迫表示に限定。

## 様式準拠

4. **topics — 新規作成フォームがシート内カード**（border + radius-lg + shadow）: ヘアライン区切りのセクションに変更。エラー状態が既定表示になっている点も、通常状態を既定にし「エラー状態の例」ラベル付きの別ブロックに分離。
5. **oauth-authorize / memo-history — グレー面パネル**（client-info / restrictions-section / memo-content が neutral-50 面）: 面2階層の原則に合わせ、背景を外しヘアライン + 余白 + タイポ階層で区画。
6. **settings — `.setting-btn` だけ角丸 10px 矩形**: `--radius-full` のピルに統一。
7. **oauth-authorize — 見出しだけ `--text-xl`**: 認証系4画面の `--text-2xl` に統一。スコープ行のチェックアイコンの紫 → `--color-neutral-500`（紫は操作専用）。
8. **全画面 lg — 橙ドットの二重出現**（サイドバー「fog •」とヘッダー「タイトル •」）: lg 以上ではヘッダータイトルのドットを非表示にし、ブランドの点をロゴに一本化。
9. **トークン外ハードコードの統一**: ヘッダーホバー `oklch(1 0 0 / 0.55)` → `--color-bg-hover`、オーバーレイ `oklch(0.21 0.006 270 / 0.28〜0.4)` → `--color-overlay`（0.28 に統一）、error ホバー直値 → `--color-error-dark`。tokens.md に3トークンを追加済み。

## UX・階層

10. **document-edit — 「保存」がファーストビュー外**: ヘッダー右に保存（btn-primary ピル）を常設。
11. **memo-history / document-history — 「この内容に戻す」が最弱の見た目**: 紫塗りのプライマリピルに昇格。
12. **履歴2画面 — 選択 UI の意味論**: ラジオ円形 → 角丸方形のチェック形状（最大2点トグルの実態に合わせる）。差分ラベルに「12:42 → 14:22 の差分」の明示を追加。行に `aria-pressed` を付与。
13. **履歴2画面 — ヘッダーの親コンテキスト欠落と提示の不一致**: ヘッダーを「戻る + 対象名（ellipsis）」に。memo-history の現メモ表示は document-history と同じプレーンテキスト + ヘアライン形式に統一。
14. **document ↔ topic-detail — 階層ヘッダーの色不一致**: document の親トピック名（紫リンク）を topic-detail と同じ `--color-neutral-900` に統一。
15. **search — ドキュメント行に右端アフォーダンスがない**: chevron（開く）を追加し、メモ行の ↗（ジャンプ）と形状で区別。
16. **timeline — ハイライト塊の下に次エントリの時刻ラベルが密着**: ハイライトの margin を調整して通常の縦リズムに合わせる。
17. **空状態の未提示**: 検索0件・ゴミ箱空の2パターンを「状態の例」ラベル付きで各 HTML に追加。
18. **password-reset — 文言と細部**: 導入文「登録されたメールアドレスに〜」が登録有無を示唆 → 中立表現に。`btn-primary:disabled` スタイル欠落 → 全認証画面に追加。説明文の1文字孤立折返し → `text-wrap: balance`。
19. **settings / timeline — スピナーが静止**: `@keyframes spin` を追加（`prefers-reduced-motion` では停止）。

## 対応不要と判断

- SSO アイコンの線画翻案（実装時にブランドガイドライン確認）
- 状態カタログとしての複数状態並置（モックの役割上妥当）
- ポップオーバーが常時開いていることによる一部テキストの隠れ（状態デモ）
- 行 padding の 14〜18px 直値（方針の基本単位内）
- 履歴画面の下部余白 150px（共通シェル由来、実害なし）

## 対応結果

1〜19 すべて修正済み（003 で再確認）。
