# デザインレビュー 007 — トークン駆動の一貫性改修（006 対応）

方針転換: 規約の文章で縛るのではなく、トークンで一貫性を持たせる。006 の指摘を「周りを見ていない独自パターン → 既存トークンへ collapse」「意図的な変化 → セマンティックトークンとして公認」の2択で全件処理した。

## トークンの変更（tokens.md）

新設:

- `--icon-lg / --icon-md / --icon-sm / --icon-xs`（20/19/16/12px）— アイコンサイズを4段のセマンティック階級として公認。18〜19px 系は md へ、14〜15px 系は sm / xs へ collapse
- `--radius-popover`（14px）/ `--popover-min-w`（160px）— ポップオーバーの中間角丸・最小幅を公認（min-width 140px は 160px へ collapse）
- `--pad-btn`（12px 24px）/ `--pad-btn-sm`（10px 20px）— ピルボタン2段。4種あった padding（12x24 / 10x20 / 11x22 / 8x14）を2段へ collapse
- `--pad-row`（16px）— リスト行の縦 padding を統一（14 / 18px を collapse）
- `--border-input`（1.3px solid neutral-300）— 入力枠線を公認
- `--color-text-inverse` — 塗りボタン・トースト上の白文字（`#fff` / `white` / `--color-bg-card` 代用をすべて置換）
- `--color-focus` / `--color-focus-danger` — フォーカスリング2色。破壊的操作の赤リングを意図的セマンティクスとして公認

collapse（トークン新設せず既存へ寄せ）:

- font-size 0.9 / 0.92 / 0.98rem → `--text-base`、1.02rem → `--text-lg`
- SVG stroke 1.3 / 1.4 → 1.5、2 → 1.8（許容レンジ 1.5〜1.8）
- `…` トリガーの `--color-neutral-400` → `--color-neutral-500`

index.md はアイコン節・ヘッダー節・フォーカス節をトークン参照へ書き換え、lg のヘッダーグリフ化（`.h-actions .icon-btn { padding: 0 }`）を公認仕様として明記。

## 構造の統一（全14ページへ展開）

- **横フレーム**: timeline / search の `.inner` に `max-width: var(--content-max)` を追加し、全画面の本文カラムを 720px に統一（006 High-1 解消）
- **検索結果行**: document.html の origin-row 型（行全体リンク・右端中央の紫 `--icon-md` アイコン・カラム幅のヘアライン）へ統一。`.result-chevron` 廃止
- **topic-detail の行**: `.row-main` ボタン方式を廃止し行全体リンクの基準形へ。「新しいドキュメント」ボタンに幅を明示し罫線をカラム幅に統一
- **topics の行ホバー**: trash 型（行ホバーなし・`.menu-btn` 色変化のみ・outline-offset -2px）へ統一
- **共通ヘッダー**: `.h-left` → `.h-back` 統一（+ flex:1 / `.h-actions` ラップ）、`.menu` は全画面 `padding: 10px 8px`、ハンバーガーホバーを欠落3画面へ追加。lg のグリフ化ブロックは維持し search の死に版は削除
- **oauth-authorize**: 上下枠線を解体し「線1本 + 線下24px / セクション上36px」のリズムへ。ラベル2種を基準形（xs/600/neutral-600/tracking-label)に統一。scope 行 `--pad-row` 化・gap:1px ハック削除
- **認証4画面**: 全て flex-start に統一し縦位置を厳密一致（password-reset の中央寄せ小カード廃止）
- **memo-history**: 「履歴」開始の線を次セクション側の border-top（上36px）へ移動（.origin 同型）

- **a11y**: `aria-expanded` 更新 JS を全ナビ画面へ、document の aria-label を「編集/削除」に統一（title 属性削除）
