# デザインレビュー 003（/polish）

対象: 全14画面。細部の品質（アラインメント・スペーシング・一貫性）に絞った仕上げパス。指摘は発見と同時に修正済み。

## 主な修正（抜粋）

### スペーシング・トークン
- スケール外の中途半端な値（2px / 4px / 5px / 6px の margin、6px 8px の padding 等）を `--space-*` スケールへ統一
- 二重スペーシングの解消: topic-detail のセクションラベル（72px）、login/signup の SSO 下（72px）、document-edit のエラー/ヘルプ文
- `0.74rem` / `1.02rem` などの直値を `--text-xs` / `--text-lg` にトークン化

### 一貫性
- 時刻表記をゼロ埋め12時間制（02:22 PM）に全画面統一（24h 混在・「19:45 PM」等の誤表記を修正）。日時・数値に `font-variant-numeric: tabular-nums`
- ミュートラベル書式（--text-xs / medium / neutral-400 / --tracking-label）を全画面統一。状態例ラベルの文言を「状態の例」に統一
- ボタン: trash ダイアログのキャンセルをピル形状に統一、button 要素の `font-family: inherit` 落ち修正、`:active` / `:disabled` / `:focus-visible` の抜けを補完
- 括弧・句読点の書式統一（全角括弧、短文メッセージは句点なし）

### 実バグ
- topic-detail: ヘッダーポップオーバーのアンカー欠落（`header.top` に `position: relative` 追加）
- topics: `.menu-btn` の opacity 基底値欠落（キーボードフォーカス時に不可視のままだった）
- document-edit: モバイルヘッダーのタイトル2行折返し → 1行 ellipsis 化

## 対応結果

すべて修正済み。構造・シェルは不変。ネスト button ゼロ・タグ開閉一致を機械確認済み。
