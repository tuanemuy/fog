# デザインレビュー 001

対象: `spec/design/pages/` 全14画面（モバイル 375 / タブレット 768 / デスクトップ 1280 のスクリーンショットによる視覚レビュー）

## 重大（レイアウト崩れ・様式違反）

1. **topics.html — 行レイアウト崩れ**: 各トピック行の操作メニューボタン（…）が行の右端に整列せず、テキストの下に独立ブロックとして落ちている。ポップオーバーのサンプルも行から遊離して画面右上に固定表示されている。行を flex にして右端整列し、ポップオーバーは対象行に紐づけて表示する。
2. **search.html — 結果カードの様式違反**: 検索結果が黒い実線ボーダーの全周カードで、本文が中央寄せになっている。様式（罫線区切りの行・左揃え・ヘアライン）に反する。`.row` + ヘアライン区切りの左揃えに修正する。

## 中程度（意味・状態表現）

3. **document-history.html / memo-history.html — 2点選択の視覚化不足**: 「2つのリビジョンを比較」なのに選択マークが1つしか付いていない。比較元・比較先の2つが選択された状態でデザインする。
4. **document.html — モバイルヘッダーのタイトル折返し**: 親トピック名「ブランド刷新」が2行に折り返して operate アイコン群と窮屈。1行 + ellipsis で切り詰める。
5. **login.html / signup.html — SSO アイコンの意味不整合**: Google に時計アイコン、Apple にスマートフォン枠アイコンが使われている。それぞれのブランドを示す簡略な線画（G モノグラム / リンゴのシルエット線画）に差し替える。
6. **oauth-authorize.html — 「できないこと」のアイコンが逆**: 制限事項の行頭が + アイコンになっており追加可能に見える。−（minus）に変更する。
7. **settings.html — エラー例の提示が不自然**: 保持期限のエラー例が「期限の数値」という別フォーム行として独立しており、同じ入力が二度あるように見える。エラー状態は保持期限フォーム自体のバリアント（状態例ラベル付き）として提示する。接続日・最終利用日が 2024〜2025 年で現在（2026年）と不整合なので合わせる。

## 軽微（許容・次回検討）

8. timeline.html — モバイルで開いた状態の操作ポップオーバーが出典ピルに重なる（サンプル状態のため許容）。
9. oauth-authorize.html — クライアント情報と「できないこと」が淡グレーパネル（面2階層原則からの軽い逸脱）。情報のまとまりとして機能しており可読性も問題ないため許容。

## 対応結果

1〜7 をすべて修正し、再スクリーンショットで解消を確認した。

- 1: `<button>` ネスト（HTML仕様違反によるボタンの吐き出し）が原因。行を `div.topic-row` + `button.row-main` + `button.menu-btn` に分離。ポップオーバーも行に追従。非表示だった作成フォームも表示状態に変更
- 2: `.result-row`（button 要素）に UA デフォルトのリセット（border / background / text-align / font-family）を追加
- 3: 比較元・比較先の2行を selected 状態に。JS も最大2点のトグル選択に変更
- 4: `.back-link` のトピック名を 1行 ellipsis に
- 5: G モノグラム / リンゴの線画 SVG に差し替え（login / signup 両方）
- 6: − アイコンに変更
- 7: エラー例を「エラー状態の例」キャプション付きの保持期限フォームのバリアントに統合し、保存ボタンを disabled 表示に。日付を 2026 年基準に修正
