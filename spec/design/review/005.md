# デザインレビュー 005 — issues.md 対応（一貫性改訂）

[spec/issues.md](../../issues.md) の指摘を、場当たり対応ではなく方針（index.md / tokens.md）の改訂 → 全14ページへの一斉展開で解消したラウンド。

## 方針レベルの変更

1. **フォント**: Web フォント（Inter + Google Fonts）を廃止し、OS 標準スタック `"Helvetica Neue", Arial, "Hiragino Kaku Gothic ProN", "Hiragino Sans", "Noto Sans JP", sans-serif` に統一。全ページから `<link>` を削除
2. **余白バランス**: シート内側の上下余白を拡大（上 40px / 下 80px〜、コンポーザー画面は 140px〜）。`--content-max` を 44rem → 50rem に広げ、ワイド画面での過剰な左右空白を縮小。ヘッダー上余白の「モバイル > デスクトップ」逆転を解消（モバイル `max(20px, safe-area+12px)` / lg 30px）
3. **サイドバー**: 240px → `--sidebar-w`（200px）。メニューの文字数に見合う幅に
4. **ホバー体系の明文化**: ①1操作対象につきホバー面は1つ（入れ子禁止）②行全体がリンクの場合のみ行ホバー面（左右へ `--space-md` 張り出し + `::before` ヘアライン）③行内に独立ボタンがある行は行ホバーなし・ボタンは色変化のみ ④ホバーで操作トリガーを出現させない（常時表示）
5. **状態例の隔離**: 通常フローに混在していた別状態の例（開いたメニュー・ハイライト・空状態・エラー等）を、アプリシェル外の `.state-examples` セクションへ移動
6. **フィードバック**: 成功通知はトースト（下部中央の浮遊ピル）に統一。インライン常設アラートを廃止。項目エラーのみ項目直下インライン
7. **文言**: 「出典メモ」「元になったメモ」→「出典」に統一。操作説明文は原則削除（残すのは誤操作防止の1行・`--text-sm` まで）
8. **区切り（線と余白）のルール**（index.md「区切り（線と余白）のルール」として明文化）: 線は境界の区切り専用（見出しの下線装飾・親子関係の表現には使わない）。線の下は常に 24px、上は同格ブロック区切り 24px / セクション開始 36px。小見出しラベルは `--text-xs`/600/`--color-neutral-600` に統一し線の下 24px・内容まで 12px。これに伴い document / document-edit の出典セクション（22px）、settings の見出し下線 → セクション上罫線化、topic-detail・topics のセクション見出し、履歴×2・trash のリード区切りを統一

## 画面固有の変更

- **タイムライン**: エントリ操作トリガー（…）を常時表示化（スマホ前提）。絞り込み解除を × アイコン化。エントリ縦リズムを対称化しフォーカス時の余白変化を解消
- **ドキュメント編集**: シームレスエディタに再構成 — 見出し・最下部ボタン行・変更理由・アラートボックス・説明文を廃止。枠なしのタイトル/本文入力（本文は `field-sizing: content` で高さ無制限、枠内スクロールなし）。保存はヘッダーの塗りピルのみ
- **ドキュメント詳細**: タイトル→日時メタ→本文のリズムに整理（タイトル下の罫線廃止）。本文見出しにリズム定義。出典行を単一ホバー面の全面リンク化（アイコンの独立ホバー廃止)
- **履歴（ドキュメント/メモ）**: 複数選択・常設チェックボックスを廃止。版の行全体をリンク化し、復元は閲覧先の操作に
- **トピック一覧**: 新規作成を常設のインライン入力行に（ダイアログ廃止）
- **トピック詳細**: トピック名をシート内見出しへ。「完了にする」を見出し直下の独立アクション行に移動
- **設定**: 説明文削減・保存成功をトースト化・数値入力の幅/内部余白を確保
- **ゴミ箱**: セット削除の縦接続線を廃止し、インデント + メタ表記で従属を表現。ヘアラインはトップレベル間のみ

## 保留（仕様レベルの論点）

- **ゴミ箱にトピックが並ぶこと自体の是非**（issues.md）: 現仕様（P-12・ADR-001）はトピックのセット削除/セット復元を前提としており、デザインでは仕様に従い表示を維持した。メモ/ドキュメントのみをゴミ箱対象とするならドメイン設計（trash）と P-12 の仕様変更が必要で、本ラウンドのスコープ外
