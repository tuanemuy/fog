# fog ロゴ

採用したアイコン・lockup と配布物の定義。

## 決定

- アイコン: **Dot & Mist**（霧の2本線 ＋ 右上の点）。霧＝雑多なメモ、点＝その中にある確かな価値。点は既存ブランドの橙ドット（`--color-accent`）を継承する
- Wordmark: **Avenir Next Medium / lowercase**、tracking −0.022em。字形は実行環境に左右されないよう、アウトライン化した SVG パスとして保持する。ウェイトを Medium に取るのは、Regular が UI サイズで華奢に見えるためである
- 橙の「点」はアイコン内の1つに集約し、lockup 末尾にドットを置かない（二重ドットを避ける）。戻る付きページヘッダーの英語タイトル横のドットはブランドの反復として存続
- ヘッダー表示規則: トップレベル5画面（タイムライン / トピック / 検索 / ゴミ箱 / 設定）はタイトルの代わりに lockup（h1 は sr-only で維持。lg 以上ではサイドバーの brand があるため非表示）。戻るボタンを持つページは lockup ではなく**対象エンティティ名**の短い英語タイトル — `topic`（トピック詳細）/ `memo`（メモ履歴）/ `document`（ドキュメント・編集・ドキュメント履歴）— を `--font-brand`（Avenir Next / Medium / lowercase）＋橙点で表示する（点は lg で非表示）。単語は「いま見ているモノ」を指す名詞に限り、操作・ビュー名（edit / history 等）はラベルにしない — 編集や履歴は対象の見出しを継承する。長くなり得る固有名（ドキュメントタイトル・トピック名）はヘッダーに置かず、シート内（`doc-title` / `doc-context`）に置く

## 構成ファイル

| ファイル | 内容 |
|---|---|
| `logo.svg` | アイコン単体（24 グリッド、線 `#191a1d` × 点 `#e8590c`） |
| `logo-mono.svg` | アイコン単色版（`currentColor`。刻印・単色印刷など差し色を使えない文脈用） |
| `lockup.svg` | アイコン ＋ Wordmark の確定 lockup（viewBox `0 0 64.7 26` — UI 実寸と 1:1 の座標系） |

デザインモック（`../pages/*.html`）にも同じ SVG を埋め込む。表示サイズは 64.7×26px（アイコン 26px、Wordmark 19px 相当）とする。華奢さの対策は Wordmark の拡大ではなく、アイコンの拡大と Medium ウェイトで行う。

## 幾何

- アイコンは 24 グリッド、線 `M4.5 12 H19.5 M7 16 H15`（stroke 1.7 / round cap）、点 `cx16.5 cy7 r1.8`
- lockup はアイコン 26px ＋ gap 10px ＋ Wordmark（font-size 19px 相当）。ベースライン y=19.02 は 19.95px のテキスト行ボックスを 26px のアイコンボックスに flexbox センタリングした値
