## 実行順序の推奨

1. account.md（アカウント作成・AIクライアント接続が他カテゴリーの前提になる）
2. timeline.md / document.md（メモ・ドキュメントのデータを作る）
3. search.md（作成済みデータを検索対象にする）
4. ai.md（AIクライアント経由の操作。account.md の接続テスト完了が前提）
5. trash.md（削除・復元。既存データを消すため後半に）
6. settings.md（保持期限・エクスポート。全データが揃った状態で実行すると検証しやすい）

各ファイルの中は**番号順ではなく記載順**に実行する。追加したケースは既存の番号を繰り上げないよう末尾採番するため、種別セクション（正常系 / 異常系 / 境界値）の中で番号が飛ぶことがある。飛んでいる番号は同じファイルの別セクションにある。
