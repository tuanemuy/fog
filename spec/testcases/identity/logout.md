# テストケース: logout

[usecases/identity.md](../../usecases/identity.md) の logout に対するテストケース。

本ユースケースはドメイン操作・永続化を行わない（セッション破棄は presentation/アダプター層の責務）。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ログイン済みユーザー（セッション由来の `userId`） | ログアウトを実行する | 正常終了（`void`）。ドメイン状態の変更・永続化は一切発生しない | |
| ログイン済みユーザー | ログアウト実行後、presentation 層の処理を確認する | presentation 層がセッションを破棄する（ユースケースはセッションに関与しない） | |
| アダプター層のセッション破棄が失敗する | ログアウトを実行する | アダプター層で `SystemError` として扱われる（ユースケース自体はエラーケースを持たない） | |
