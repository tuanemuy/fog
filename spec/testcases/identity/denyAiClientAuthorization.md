# テストケース: denyAiClientAuthorization

[usecases/identity.md](../../usecases/identity.md) の denyAiClientAuthorization に対するテストケース。

本ユースケースはドメイン操作・永続化を行わない（プロトコル上の拒否応答はアダプターの責務）。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ログイン済みユーザーが OAuth 認可画面で「拒否する」を押した | 拒否を実行する | 正常終了（`void`）。`AiClientConnection` は作成されない（拒否の事実はドメインに残らない） | |
| 拒否実行後 | `listAiClientConnections` で同ユーザーの接続一覧を取得する | 拒否した認可に対応する接続は一覧に存在しない | |
| 拒否実行後 | アダプター層の応答を確認する | アダプターがクライアントへプロトコル上の拒否応答（エラーリダイレクト）を返す（ユースケースの責務外であることの確認） | |
