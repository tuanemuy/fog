# シナリオ: アカウントと認証

## S-AC-01 アカウント登録（パスワード）

1. 未ログインでトップにアクセスすると、ログイン画面に案内される
2. 「アカウント登録」を選び、メールアドレスとパスワードを入力する
3. 登録が完了し、ログイン状態でタイムラインが表示される

異常系:

- 既に登録済みのメールアドレスの場合、その旨が表示され、ログインへの導線が示される
- パスワードが要件（最低長等）を満たさない場合、入力欄にエラーが表示され再入力できる
- メールアドレスの形式が不正な場合、エラーが表示される

## S-AC-02 アカウント登録・ログイン（SSO）

1. ログイン画面で「Googleで続行」等のSSOボタンを押す
2. プロバイダの認証画面で許可する
3. 初回なら自動でアカウントが作成され、以後は同じ操作でログインになる。タイムラインが表示される

異常系:

- プロバイダ側でキャンセルした場合、ログイン画面に戻り、エラーではなく中断として扱われる
- プロバイダ側の認証に失敗した場合、失敗した旨が表示され再試行できる

## S-AC-03 ログイン（パスワード）

1. ログイン画面でメールアドレスとパスワードを入力する
2. タイムラインが表示される

異常系:

- 認証情報が誤っている場合、「メールアドレスまたはパスワードが正しくない」と表示される（どちらが誤りかは明かさない）
- 未ログインで保護されたURLに直接アクセスした場合、ログイン画面へ誘導され、ログイン後に元のURLへ戻る

## S-AC-04 ログアウト

1. メニューから「ログアウト」を選ぶ
2. ログイン画面に戻る。以後、保護された画面にはアクセスできない

## S-AC-05 AIクライアントを接続する（OAuth認可）

1. LLMアプリ側で fog をコネクタとして追加する
2. ブラウザで fog の認可画面が開く。未ログインならまずログインする
3. 認可画面に「このAIクライアントに許可される操作」（読み取り・書き込み。ハードデリート・ゴミ箱・履歴操作は含まれないこと）が表示される
4. 「許可する」を押すと、LLMアプリに戻り、以後AIがユーザーの代理として読み書きできる

異常系:

- 「拒否する」を押した場合、接続は成立せず、LLMアプリ側に拒否が伝わる
- 認可リクエストが不正（改ざん・期限切れ等）な場合、許可ボタンは表示されずエラーが表示される

## S-AC-06 接続済みAIクライアントを確認・失効する

1. 設定画面の「接続済みAIクライアント」を開く
2. クライアントごとに名前・接続日時・最終利用日時が一覧表示される
3. 不要になったクライアントの「接続を解除」を選び、確認して実行する
4. 以後そのクライアントのトークンは無効になり、API呼び出しは認可エラーになる

エッジケース:

- 接続済みクライアントが1件もない場合、その旨と接続方法の案内が表示される
- 解除済みクライアントで再度使いたい場合は、S-AC-05 の接続をやり直す

## S-AC-07 パスワードを忘れた・変更する

1. ログイン画面の「パスワードをお忘れですか？」からメールアドレスを入力する
2. 届いたメールのリンクから新しいパスワードを設定し、ログインし直す
3. ログイン中は、設定画面から現在のパスワードを入力のうえ新しいパスワードに変更できる

異常系:

- 未登録のメールアドレスを入力しても「登録されていれば送信された」旨のみ表示する（登録有無を明かさない）
- リセットリンクが期限切れの場合、その旨が表示され再送をやり直せる
- パスワード変更時に現在のパスワードが誤っている場合、変更できない

エッジケース:

- SSOのみで登録したユーザー（パスワード未設定）には、パスワード変更の項目を表示しない
