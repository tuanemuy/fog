# シナリオ: ゴミ箱

## S-TR-01 ゴミ箱を一覧する

1. ゴミ箱画面を開くと、ソフトデリート済みの項目（メモ / ドキュメント / トピック）が削除日時付きで一覧表示される
2. 各項目に、保持期限（既定30日）までの残り日数が分かる表示がある

エッジケース:

- ゴミ箱が空の場合、その旨が表示される
- トピックを削除した場合、配下ドキュメントも一覧に現れるが、トピックとセットである関係が分かる表示になる

## S-TR-02 項目を復元する

1. ゴミ箱で項目の「復元」を選ぶ
2. メモはタイムラインの元の位置へ、ドキュメントは元のトピック配下へ戻る
3. トピックを復元すると、セットで削除された配下ドキュメントも一緒に戻る

エッジケース:

- ドキュメントだけを個別に復元しようとしたとき、所属トピックもゴミ箱内にある場合は、トピックも一緒に復元される旨が示され、確認のうえセットで復元される
- 復元しようとしたドキュメントの所属トピックが既にハードデリートされている場合、復元先トピックの選択（既存から選ぶ・新規作成する）が求められ、選択のうえ復元される
- 復元したメモ・ドキュメントの出典リンクは復元後に再び機能する（「削除済み」表示が解消される）

## S-TR-03 項目を完全に削除する（ハードデリート）

1. ゴミ箱で項目の「完全に削除」を選ぶ
2. 「リビジョン履歴ごと完全に消え、元に戻せない」旨の確認が表示される
3. 1回の処理上限に達した場合、残件数と「削除を続ける」が表示される
4. 処理が完了すると項目は履歴ごと消去される

補足:

- この操作は人間のUI専用。AIクライアントにはハードデリートを許可しない
- トピックを完全に削除する場合、セットの配下ドキュメントも履歴ごと消去される旨が確認に含まれる
- 完全削除を開始した項目、配下項目、所属トピックは復元できない
- 途中で通信または保存処理が失敗した場合も一覧を再取得し、「削除を続ける」で残りから再開する

## S-TR-04 ゴミ箱を空にする

1. ゴミ箱画面で「空にする」を選ぶ
2. 全件を完全に削除する旨の確認と対象件数が表示される
3. 1回の処理上限に達した場合、削除済み件数と残件数が表示される
4. 「残りを削除」を繰り返すと、ゴミ箱内の全項目が履歴ごと削除される

エッジケース:

- 途中で通信または保存処理が失敗した場合も一覧を再取得し、削除済み項目を表示へ反映する
- 削除処理を開始した項目は復元できず、後続の「残りを削除」「削除を続ける」または自動削除で処理を再開する

## S-TR-05 保持期限による自動削除

1. ソフトデリートから保持期限（既定30日、設定で変更可能）が経過した項目は、自動でハードデリートされる
2. ユーザー操作は不要。期限内であればいつでも復元できる

エッジケース:

- 保持期限を短く変更した場合、既にゴミ箱にある項目にも新しい期限が適用される（次回の自動削除で消える）
