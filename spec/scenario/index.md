# シナリオ一覧

利用者視点でシステムが提供する操作を列挙する。詳細は各カテゴリーのファイルを参照。

登場する利用者:

- **人間ユーザー**: fog のWeb UIを直接操作する本人
- **AIクライアント**: ユーザーが認可したLLMアプリ。MCP / REST API 経由でユーザーの代理として読み書きする

## カテゴリー

### [アカウントと認証](./account.md)

- アカウント登録（パスワード / SSO）
- ログイン / ログアウト
- パスワードのリセット・変更
- AIクライアントの接続（OAuth認可）
- 接続済みAIクライアントの一覧・失効

### [タイムライン（メモ）](./timeline.md)

- メモを投稿する
- タイムラインを閲覧する（日付見出しグルーピング）
- キーワードで絞り込む / 日付へジャンプする
- メモを編集する
- メモの履歴を見る / 差分を見る / ロールバックする
- メモを削除する（ソフトデリート）
- メモから出典先ドキュメントへ移動する

### [ドキュメントとトピック](./document.md)

- トピックを作成・編集する
- トピックを完了にする / 完了を解除する
- トピック一覧・詳細を閲覧する（配下ドキュメント・関連メモ）
- ドキュメントを作成・編集する
- ドキュメントの履歴を見る / 差分を見る / ロールバックする
- ドキュメントの「元になったメモ」から出典メモへ移動する
- ドキュメント / トピックを削除する（ソフトデリート）

### [検索](./search.md)

- キーワードでメモ・ドキュメントを横断検索する（FTS5全文検索）
- トピックで検索結果を絞り込む
- 検索結果から各項目へ移動する

### [ゴミ箱](./trash.md)

- ゴミ箱の中身を一覧する
- 項目を復元する（トピックは配下ドキュメントごと）
- 項目を完全に削除する（ハードデリート）
- ゴミ箱を空にする
- 保持期限経過による自動ハードデリート

### [AI連携](./ai.md)

- AIに雑に記録してもらう（post_memo）
- AIに思い出して探してもらう（search / get / recent_memos）
- AIに議論をドキュメントに起こしてもらう（create_document / create_topic / 出典紐付け）
- AIがメモ・ドキュメントを修正する（update_memo / edit_document）
- AIが項目を削除する（ソフトデリートのみ）→ 人間が復元する
- AIがトピックを整理する（create_topic / update_topic・完了の切り替え）

### [設定とデータ管理](./settings.md)

- ゴミ箱の保持期限を変更する
- 全データをエクスポートする（Markdown等の可搬形式）
