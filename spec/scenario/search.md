# シナリオ: 検索

## S-SE-01 キーワードで横断検索する

1. 検索画面でキーワードを入力する
2. SQLite FTS5 の全文検索が実行され、メモとドキュメントを横断した結果が表示される
3. 各結果には種別（メモ / ドキュメント）・原文スニペット・タイムスタンプ・所属トピック（ドキュメントの場合）が表示される
4. 結果を選ぶと、メモならタイムライン上の位置、ドキュメントならドキュメント画面へ遷移する

エッジケース:

- 一致する結果がない場合、「見つからなかった」旨が表示される
- キーワードが未入力の間は検索は実行されない（トピック配下の閲覧はトピック詳細画面が担う）
- ゴミ箱内の項目はヒットしない
- 完了済みトピック配下のドキュメントはヒットする
- 日本語3文字以上と1〜2文字の短語のどちらも検索できる
- メモ・ドキュメントの書き込み完了直後から検索結果へ同期反映される

## S-SE-02 トピックで絞り込む

1. 検索画面でトピックを選択して検索する
2. そのトピック配下のドキュメントと、その出典メモに絞られた結果が表示される
3. 絞り込みを解除すると全体の横断検索に戻る

## S-SE-03 AIクライアントによる検索

AIクライアントは同一のFTS5全文検索を search API として利用する（→ S-AI-02）。人間UIとAPIで検索の挙動（ヒット範囲・順位・除外規則）は一致する。
