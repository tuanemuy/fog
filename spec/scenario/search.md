# シナリオ: 検索

## S-SE-01 キーワードで横断検索する

1. 検索画面でキーワードを入力する
2. 全文検索が実行され、メモとドキュメントを横断した結果が表示される
3. 各結果には種別（メモ / ドキュメント）・原文スニペット・タイムスタンプ・所属トピック（ドキュメントの場合）が表示される
4. 続きがある場合は「もっと読む」で追加取得でき、重複も欠落もなく読み進められる
5. 結果を選ぶと、メモならタイムライン上の位置、ドキュメントならドキュメント画面へ遷移する

エッジケース:

- 一致する結果がない場合、「見つからなかった」旨が表示される
- キーワードが未入力の間は検索は実行されない（トピック配下の閲覧はトピック詳細画面が担う）
- ゴミ箱内の項目はヒットしない
- 完了済みトピック配下のドキュメントはヒットする
- 投稿・編集した項目は直後の検索から必ずヒットする（反映待ちは無い）

## S-SE-02 トピックで絞り込む

1. 検索画面でトピックを選択して検索する
2. そのトピック配下のドキュメントと、その出典メモに絞られた結果が表示される
3. 絞り込みを解除すると全体の横断検索に戻る

## S-SE-03 AIクライアントによる検索

AIクライアントも同じ全文検索を利用する（→ S-AI-02）。人間UIとAIクライアントで検索の挙動（ヒット範囲・除外規則）は一致する。
