# ADR-003 出典リンク先のハードデリート後の表示

## ステータス

承認済み

## コンテキスト

出典リンクの参照先（出典メモ、または参照先ドキュメント）がソフトデリートされた場合の挙動は要件で定義済み（「削除済み」として表示を残す）。しかし参照先がハードデリートされた場合の出典表示は未定義だった。ハードデリートは「リビジョン履歴ごとの完全消去」（requirements.md 4.3）である。

## 決定

参照先がハードデリートされた場合、出典リンク自体を消し、相手側に表示を残さない。メモ側の「→ ドキュメントX」導線、ドキュメント側の「元になったメモ」一覧の項目とも表示されなくなる。

## 検討した代替案

- **「完全に削除されたメモ」として恒久的な表示を残す** — ハードデリートの意味（完全消去）と矛盾する。タイトルや日時など断片情報の残存自体が消去の意図に反する。不採用
- **リンクは残しリンク先だけ消す** — 参照先のない壊れたリンクが恒久的に残り、ユーザーに混乱を与える。不採用

## 影響

- ハードデリートは出典リンクの削除を伴う（リンクテーブル上の参照も消去する）
- ドキュメントの「元になったメモ」一覧は、出典が全てハードデリートされると空になり得る。ドキュメント自体の内容には影響しない
