# ADR-006 メモの更新は全文置換のみ（パッチ対象外）

## ステータス

承認済み

## コンテキスト

requirements.md 4.3「AIへの編集インターフェース」はメモ・ドキュメント共通の節として「原則パッチ形式とする。全文指定は新規作成・明示的な全面書き直しに限定」と規定している。一方、メモは内部構造を持たないアトム（要件2章。上限10,000文字の非構造プレーンテキスト）であり短文が主である。プレーンテキストへのパッチ適用は、一意一致の失敗（同一文字列の複数出現・対象文字列の不在）などの失敗モードを増やし、短文に対しては利得がない。

## 決定

`update_memo` は全文置換のみとする。パッチ機構（`DocumentPatch`）はドキュメント専用とする。

「原則パッチ」の趣旨（該当箇所だけを差し替え、意図しない全文消失を防ぐ）は、メモにおいてはリビジョン履歴による復元可能性で担保する（編集のたびにリビジョンが自動で積まれ、過去内容へロールバックできる）。

## 検討した代替案

- **メモにもパッチを提供する** — 短文のプレーンテキストに対して一意一致失敗などの失敗モードが増える一方、差分編集の利得は小さい。不採用

## 影響

- MCP ツール定義で `update_memo` は全文指定と明記する
- パッチ形式の編集（`edit_document` / `DocumentPatch`）は knowledge ドメインのドキュメントに限定される
- ドキュメント側はパッチが原則のままだが、全文置換は `edit_document` の `replaceAll` モード（ユーザーが明示的に全面書き直しを求めた場合に限る）として存在する（requirements 4.3 の「明示的な全面書き直し」の経路。詳細は domains/knowledge.md）
