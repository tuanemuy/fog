# 異常系-1: 登録済みメールでの登録は重複エラーになり、ログインへの導線が出る

**結果**: PASS
**対応する受け入れ基準**: AC-12（manual TC-14）
**実行時間**: 約35秒

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | ログアウト状態で `/signup` を開く | 登録フォームが表示される | 見出し「アカウント登録」・メール欄・パスワード欄・「登録する」・「ログイン」リンクが表示。未ログイン（リダイレクトなし） | PASS |
| 2 | `test@example.com` / `password123` を入力して「登録する」を押す | メールアドレス欄付近に「このメールアドレスは登録済みです」が表示され、登録されない | URL は `/signup` のまま。メール欄の直下（textbox 直後の paragraph）に「このメールアドレスは登録済みです」。タイムラインへの遷移なし | PASS |
| 2-a | 画面 / HTML ソースに英語の生メッセージが出ていないか確認 | `EMAIL_ALREADY_REGISTERED` / `UNIQUE_VIOLATION` 等が出ない | `document.documentElement.outerHTML` に対する `/EMAIL_ALREADY_REGISTERED\|UNIQUE_VIOLATION\|already\|violation/i` テストが `false`。body の可視テキストも日本語のみ | PASS |
| 3 | 表示されたログインへの導線を押す | `/login` へ遷移する | 「このメールアドレスでログインする」リンク（`href="/login"`）が表示され、クリックで `http://localhost:3000/login` へ遷移。ログイン画面（見出し「ログイン」・メール／パスワード欄・「アカウント登録」・「パスワードを忘れた」）が表示 | PASS |

## 補足

- エラーは**フォーム上部の汎用エラーではなく、メールアドレス欄の直下**にレンダリングされていた（アクセシビリティツリー上、`textbox "メールアドレス"` の直後の `paragraph`）。
- 入力したメールアドレスの値（`test@example.com`）はエラー後も保持されていた。
- 本ケースでは新規ユーザーは作成していない。
