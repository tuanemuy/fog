# TC-05: コンポーザーは 1 行のピルのまま複数行へ伸びる

**テストソース**: `.thread/22/testing.md` 確認項目 5
**アカウント**: `fog-verify-2026-09-12@example.com`
**ビューポート**: 390 × 844
**証跡**: TC-05.png / TC-05.webm

「BOX」= `textarea[aria-label="メモを入力"]` と `button[aria-label="メモを追加"]` の両方を含む最も内側の祖先要素。

| # | 操作 | 期待結果 | 観測した内容 |
|---|---|---|---|
| 1 | `/` を開き、画面下端のコンポーザーを見る | 左端に送信アイコン、その右に入力欄を持つ 1 本のピル（角丸が高さの半分）。シートの上に浮いて影を持つ | BOX: 矩形 x=40 / y=762 / 310×52、`border-radius: 26px`（高さ 52 の半分）、`box-shadow` の最後の層が `oklch(0.21 0.006 270 / 0.18) 0px 12px 36px 0px`、`background-color: oklch(0.96 0.003 286 / 0.88)`。BUTTON `メモを追加` は x=56（左）、TEXTAREA は x=97（右）。TEXTAREA の `placeholder` は `"メモを入力…"`、`max-height: 168.562px`、`line-height: 28.12px`（168.562 / 28.12 = 5.99） |
| 2 | 何も入力していない状態で送信ボタンを見る | `disabled`（押せない見た目） | `button[aria-label="メモを追加"]`: `disabled = true`、`color = oklch(0.875 0.006 278)`、svg 1 個、27×28 |
| 3 | 1 文字入力する | 押せるようになる | `週` を入れると `disabled = false`。BOX は 310×52 のまま |
| 4 | 改行して 3 行にする（`週末の買い出し` / `- 牛乳と卵` / `- コーヒー豆（浅煎り）`） | 箱は下端を固定したまま上へ伸び、角丸は 1 行のときの半径のまま。送信アイコンは最終行の高さにそろう | BOX: y=706 / 310×108（bottom は 814 のまま、1 行時の bottom 814 と同じ）、`border-radius: 26px`（変化なし）。TEXTAREA: y=718 / 237×84。BUTTON: y=774 / centerY=788（TEXTAREA の最終行は y=774〜802、その中心 788 と一致）。1 行時の BUTTON も y=774 / centerY=788 |
| 5 | 6 行にする | — | BOX: y=622 / 310×192。TEXTAREA: 237×169（`scrollHeight = 169` = `clientHeight`）。BUTTON: y=774 / centerY=788 |
| 6 | 8 行にする | 6 行を超えると箱はそれ以上伸びず、入力の中がスクロールしてキャレットのある末尾が見える | BOX: y=622 / 310×192（6 行時と同一）。TEXTAREA: `clientHeight = 169` のまま、`scrollHeight = 225`、`scrollTop = 51`、`selectionStart = 31` = `value.length`（末尾）。`border-radius` は 26px のまま。BUTTON: y=774 / centerY=788 |
| 7 | 入力をすべて消す | 1 行のピルに戻り、送信ボタンは再び `disabled` | キーボード（Ctrl/Cmd+A → Backspace）で消すと `value = ""` / `disabled = true`。<br>なお `agent-browser` の `fill` に空文字を渡した場合は `value = ""` になっても `disabled = false` のままだった（DOM の値だけが変わり React の state が更新されない経路。判定に使える観測ではないので、キーボードでの消去を正とした） |
| 8 | 「音声で入力」のボタンを探す | 無い | BOX 内の `button` は `メモを追加` の 1 つだけ |
| 9 | 送信中のアイコンを見る | 回るスピナーに変わる | 送信ボタンを押した直後から、ボタンは `disabled = true`、中の svg の class が `size-icon-md shrink-0 animate-spin` / `animation-name: spin`。完了後は `size-icon-md shrink-0` / `animation-name: none` |
| 10 | 伸縮の途中でシートの中身が横にはみ出さないか見る | 横にはみ出さない | 全状態で `main.scrollWidth = 362` = `main.clientWidth = 362`、`document.documentElement.scrollWidth = 390` = `window.innerWidth = 390` |

## 補足（環境への影響）

- Step 9 の観測のため、メモ `スピナー観測用` を 1 件投稿した（タイムラインに残っている）。
