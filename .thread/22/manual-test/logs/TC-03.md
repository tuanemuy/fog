**ビューポート**: 390 × 844（末尾のみ 1280 × 900）
**証跡**: TC-03.png / TC-03.webm

| # | 操作 | 期待結果 | 観測した内容 |
|---|---|---|---|
| 1 | 390×844 で `/topics` を開き、ヘッダー右の「メニュー」を押す | ボトムシートが開く | `dialog` 要素が `open = true`。`aria-label="メニュー"`、`role` 属性なし、`aria-modal` 属性なし。`d.matches(':modal')` は `true` |
| 2 | シートの形を見る | 画面下端から迫り上がる白いカード、上辺だけ丸く、中央上部に短い横棒（ハンドル）。カードの左右はシート本体と同じ横フレームにそろう | `dialog` の矩形 x=14 / 幅 362 / top=494 / bottom=844（ビューポート下端）。直下の `DIV` が同じ矩形で `border-radius: 26px 26px 0px 0px` / `background-color: oklch(1 0 0)`。その中の `DIV` が 36×4px、`border-radius: 9999px`、`background-color: oklch(0.875 0.006 278)`、中心 X=195（`dialog` の中心 X=195 と一致）、`aria-hidden="true"`。シート本体（`main`）の矩形も x=14 / 幅 362 |
| 3 | 背後の覆いを見る | 背後は暗い覆いになり操作できない | `::backdrop` の `background-color` は `oklch(0.21 0.006 270 / 0.28)` |
| 4 | 項目の並びと現在地の示し方を見る | 5 項目が縦に並び、間にヘアラインが 1 本ずつ。現在地だけ太字で行頭に橙の丸（`aria-current="page"`）、他の項目の行頭は丸が見えない | `nav` 内の `a` は 5 つ: 「タイムライン」`/`・「トピック」`/topics`・「検索」`/search`・「ゴミ箱」`/trash`・「設定」`/settings`。「トピック」だけ `aria-current="page"` / `font-weight: 600`、他は `aria-current` なし / `font-weight: 500`。各 `a` は 314×55〜56px で、2 番目以降に `border-top: 1px oklch(0.945 0.004 286)`（1 番目は 0px）。各 `a` の中に 6×6px・`border-radius: 9999px` の `SPAN` があり、`background-color` は「トピック」だけ `oklch(0.63 0.13 292)`、他の 4 つは `rgba(0, 0, 0, 0)`。この色はトークンの `--color-primary`（`--color-accent` は `oklch(0.62 0.19 40)`） |
| 5 | ハンドルを押す | 装飾（`aria-hidden`）で、押しても何も起きない | ハンドル `DIV`（`aria-hidden="true"`）を `click()` した後も `dialog.open = true` |
| 6 | 開いている間、背後のシートがスクロールするか見る | スクロールしない | `main.scrollTop = 200` を代入しても値は 0 のまま。`body` / `html` の `overflow` は両方 `visible`。（`/topics` はこの時点で `main` の内容が 1 画面に収まっており、この代入だけではスクロール抑止の有無を切り分けられない） |
| 7 | シートの外（暗い覆いの部分）を押す | 閉じる | 座標 (195, 200) を mouse down/up → `dialog.open = false`、URL は `/topics` のまま |
| 8 | もう一度「メニュー」を押し、Escape キーを押す | 閉じる | `dialog.open = false` |
| 9 | もう一度「メニュー」を押し、項目「検索」を押す | `/search` へ遷移し、シートは閉じている | URL が `/search`、`dialog.open = false` |
| 10 | 幅を 1280 × 900 に変え、ヘッダーを見る | メニューボタンもボトムシートも出ない | `header button[aria-label="メニュー"]` は DOM にあるが矩形 0×0。`dialog` は DOM にあるが `open = false` / 矩形 0×0 |
