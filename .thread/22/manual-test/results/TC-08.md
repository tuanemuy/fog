## 失敗詳細

- **失敗ステップ**: Step 3 / 4b / 7
- **期待**: 差し替えで行の高さも位置も変わらない。読み上げは `aria-busy` の付いた `role="status"` が 1 か所
- **実際**: スタンドインの行数・文字長が実データと違う画面（`/trash`・`/settings`）で行位置と高さが動く。`/search` だけ `aria-busy` の要素が `role` を持たず、読み上げは子の `LoadingRow`
- **画面状態**: 帯はいずれの画面でも静止し、実 DOM に被さっている。見出し・冒頭の一文は本物の文字のまま
- **三分**: **手順書起因**
- **根拠**: spec の規定は `tokens.md`「スケルトンは実画面の DOM に被せる形で、固有の寸法を持たない」とモックの「実 DOM に被せ、文字を透明にして同じ行高を保つ」までで、行数一致は求めていない（スタンドインは固定の行数を持つ）。`/search` も `LoadingRow` が `role="status"` を持ち「1 か所だけ読み上げられる」は満たす（`SearchSkeleton` の JSDoc どおりの意図的な形）。
