# Issue 化する候補 — Issue #22 のスコープ外

ステップ 9〜16 の下書きにある「担当外への変更要望」「モックとの差」のうち、
plan.md のスコープ（`apps/web` の見た目の載せ替え）に収まらないもの。統合
（この作業）で処理したものは `integration.md` にある。`styles/` の旧 CSS・
`docs/` の更新・adr.md への統合はステップ 17 が持つので、ここには含めない。

## 挙動

- **ゴミ箱と確認ダイアログが保持日数を出せない**（step-11・15）。モックは
  「30日後に完全に削除されます」と書くが、保持期限は P-13 で変えられ、
  `listTrash` の結果にも確認ダイアログにも日数が無い。画面は「保持期限を過ぎると」
  に置き換えてある。日数を出すならユースケースの戻り値に足す変更が要る
- **ゴミ箱のセット関係が 1 ページに収まらないと見えない**（step-15）。所属トピックが同じページ
  （`TRASH_PAGE_LIMIT` 100 件）に無いセット削除のドキュメントは、トピックの下に置けないので普通の
  ドキュメントの行として出る。`spec/pages/index.md` P-12 の「セット関係が分かる表示」を、
  100 件を超えるゴミ箱ではインデントで満たせない
- **メモ履歴に「現在の内容」が無い**（step-13）。モックは一覧の上に現在の本文を
  置くが、P-05 に無く、`listMemoRevisions` はメモ本文を返さない。削除済みメモの
  履歴も読めるので `getMemo` では代わりにならない

## `components/ui` へ引き上げる候補

いずれも今は 1 つの持ち場でしか使わないか、統一がデザインの決め直しになる。

- **バッジ**（step-14）。検索チップの「完了」・トピックの「完了済み」・ゴミ箱の
  種別ピル・履歴の「比較元 / 比較先」が、地・文字色・語まで画面ごとに違う。
  語の揺れ（「完了」と「完了済み」）を含めてモック側の決め直しが先
- **エクスポートの進行中の表示**（step-14）。続き読み込みのスピナー行は 3 画面
  （検索・タイムライン・ゴミ箱）が同形だったので `components/ui/LoadingRow` に
  引き上げた。エクスポートの進行中だけは行の `actions` に入るインライン表示で
  形が違うので、`ExportPanel` に残している
- **行全体のトグル `RowToggle`**（step-13）。履歴の版の行だけが使う。ほかの画面に
  同じ行が出たときに引き上げる
- **作成導線の行 `AddRow`**（step-11）。トピック一覧とトピック詳細だけが使う。
  ADR-017 が挙げた「2 種に入らない行」の 3 種目
- **遷移しない行**（step-11・12）。`knowledge/OriginRow` の削除済み行と
  `documents/SourceMemoLine` が、同じ「時刻＋2 行の本文」を別々に持つ。行の箱
  だけでなく中身まで 1 つにするかは、出典の行の設計の判断
- **`timeline/MemoEntry` の `actorLabel`**（step-12）。ドキュメントの競合警告が
  タイムラインから import している。共有の置き場へ移す

## デザイン / spec の判断

- **「もっと読む」の段の色**（step-14）。モックの `.more-btn` は
  `--color-primary-dark` の文字だが、ADR-016 の `outline` は `--color-neutral-900`。
  実装は段に寄せた。モックを正とするならボタンの段の改修
- **年を落とす日時の書式**（step-13・14）。モックは「7月20日 12:30」と書く。
  どの年かを省けるかは描画時の現在時刻に依るので、`presentation/time.ts` は年を
  持つ書式だけを提供している。タイムラインの「今日 / 昨日」も同じ理由で入れていない
- **P-08 の領域名**（step-12）。`spec/pages/index.md` は「元になったメモ」、
  モックと実装は「出典」
- **spec/manual-tests の文言**（step-09・12）。ログイン画面の導線
  （「パスワードをお忘れですか？」→「パスワードを忘れた」）、出典の選択の手順
  （「検索」ボタンの撤去）が実装と食い違う。plan.md のスコープ外
- **モックに状態例が無い表示**（step-12・15）。ドキュメント削除成功のトースト、
  出典ピッカーを開いた直後、ゴミ箱でトピックの下の行が操作中のとき
