# TC-E07: 存在しないパスで 404 画面が出る

**結果**: PASS
**対応する受け入れ基準**: AC-19 / AC-29（既存動線の無傷性）

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | 未認証で `http://localhost:3000/no-such-page` を開く | 「ページが見つかりません」 | `heading "ページが見つかりません" [level=1]` + `link "タイムラインへ"`。`curl` のステータスは **404**（307 ではない = 認証ガードより not-found が先に効いている） | PASS |
| 2 | 「タイムラインへ」を押す（未認証） | `/` へ | `/` へ向かい、認証ガードで `http://localhost:3000/login?redirect=%2F` に着地。ログインフォームが出る | PASS |
| 3 | 認証済みで `/no-such-page` を開く | 「ページが見つかりません」 | `main` = 「ページが見つかりません / URL が変わったか、削除された可能性があります / タイムラインへ」 | PASS |
| 4 | 「タイムラインへ」を押す（認証済み） | `/` に戻る | `http://localhost:3000/`、`main` = 「まだメモがありません」 | PASS |

ルーターの not-found 経路は DO 移行の影響を受けていない。
