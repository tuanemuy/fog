# TC-002: 未認証のトップページが Cloudflare 構成の dev サーバーでログイン画面に誘導される

**結果**: PASS
**実行時間**: 約40秒
**セッション**: verify-auth

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | dev サーバーが Cloudflare 構成で起動していることを確認（起動済みのため `ps aux` でプロセス確認 + `apps/web/package.json` のスクリプト定義を目視） | `vite.config.cloudflare.ts` が使われている | プロセスは `vite.js dev --config vite.config.cloudflare.ts`。`"dev": "pnpm dev:cf"` / `"dev:cf": "vite dev --config vite.config.cloudflare.ts"` | PASS |
| 2 | 未認証セッションで `http://localhost:3000/` を開く | ログイン画面（見出し「ログイン」、メールアドレス／パスワード欄、「ログイン」ボタン）が描画される | `http://localhost:3000/login?redirect=%2F` に遷移し、`heading "ログイン" [level=1]` / `textbox "メールアドレス" [required]` / `textbox "パスワード" [required]` / `button "ログイン"` を確認。500 やビルドエラーなし | PASS |
| 3 | `curl -i http://localhost:3000/` | `HTTP/1.1 307` と `location: /login` | `HTTP/1.1 307 Temporary Redirect` / `location: /login?redirect=%2F` | PASS（注記あり） |

## 注記

- Step 3 の `location` は testing.md の記載（`/login`）に対し実測は `/login?redirect=%2F`。リダイレクト先は `/login` で一致しており、`?redirect=` はエッジケース1 で検証している `_app.tsx` の既存リダイレクト往復仕様と整合するため退行ではない。testing.md の期待値表記の方が実態より簡略。
- 307 は `apps/web/app/routes/_app.tsx` の `beforeLoad` による既存挙動であり正常。
