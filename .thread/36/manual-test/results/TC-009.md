## 備考

- **`pnpm test:unit` のテスト件数について**: testing.md の期待値表はファイル数（24）のみを明示しており、テスト件数の期待値は書かれていない。実測 409 件はベースライン 424 件から 15 件減で、削除された2ファイル（`inMemoryQueueDispatcher.test.ts` / `inProcessRelayTrigger.test.ts`）の分に相当する。減少がこの2ファイルに閉じていることを `git diff --name-status main...HEAD` で確認済みのため、期待どおりの減り方と判定した。
- `pnpm lint` の `Found 2 infos.` は Biome の設定移行案内（`biome migrate` の推奨）で、エラーではなく exit 0。本 Issue の変更とは無関係。
