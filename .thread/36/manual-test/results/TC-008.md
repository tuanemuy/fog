# TC-008: `pnpm start` のスクリプト定義が Cloudflare 構成を指している（実行しない）

**結果**: PASS
**実行時間**: 約1秒（目視確認のみ）

対応する確認項目: testing.md「確認項目8」（AC-3）

> **`pnpm start` / `pnpm preview` は実行していない。** testing.md 確認ポイントおよび Issue #40 のとおり、`wrangler dev` は本 Issue 以前から workerd の起動時に `Disallowed operation called within global scope.` で落ちるため、実行検証の対象外。定義の目視確認のみを行った。

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | `apps/web/package.json` の `"start"` / `"start:cf"` を目視確認 | `"start": "pnpm start:cf"` / `"start:cf": "wrangler dev"` | `apps/web/package.json:13` → `"start": "pnpm start:cf"`、`apps/web/package.json:14` → `"start:cf": "wrangler dev"` | PASS |
| 2 | ルート `package.json` の `"start"` の委譲先を目視確認 | `"start": "pnpm --filter @repo/web start"` | `package.json:15` → `"start": "pnpm --filter @repo/web start"`（併せて `package.json:16` に `"start:cf": "pnpm --filter @repo/web start:cf"`） | PASS |
| 3 | `"start:node"` / `"start:gcp"` が両方の `package.json` から消えていることを確認 | 残っていない | `grep -n '"start' package.json apps/web/package.json` のヒットは上記4行のみ。`start:node` / `start:gcp` は0件。さらに `grep -nE '"[a-z]+:(node\|aws\|gcp)"'` を両ファイルに掛けても0件（`:node` / `:aws` / `:gcp` サフィックスのスクリプトは1本も残っていない） | PASS |

## 備考

- ステップ3 の確認は testing.md 記載の `start:node` / `start:gcp` に加え、`build:*` / `dev:*` / `db:migrate:*` / `test:integration:*` / `deploy:aws:*` を含む全ランタイムサフィックスに拡張して検証した（すべて0件）。
