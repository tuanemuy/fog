# TC-001: 撤去後の依存構成で `pnpm install --frozen-lockfile` が通る

**結果**: PASS
**実行時間**: 約6秒

対応する確認項目: testing.md「確認項目1」（AC-2 / AC-9）

## 前提の記録

- 実行前に dev サーバーが起動中であることを確認済み
  - `lsof -nP -iTCP:3000 -sTCP:LISTEN` → PID 20251 (node) が LISTEN
  - `pgrep -fl vite` → `vite.js dev --config vite.config.cloudflare.ts`
  - `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/login` → `200`
- `git status --porcelain` にトラッキング済みファイルの変更なし（lockfile はコミット済みの状態）

## 備考

- 手順2 の「`postinstall` で走り切っていることを出力で確認」については、`node_modules` が既に lockfile と整合していたため pnpm が install 自体をスキップし、ライフサイクルスクリプトが発火しなかった。testing.md が手順文中で名指ししているコマンド（`pnpm --filter @repo/web exec wrangler types`）を直接実行して成功と冪等性（差分ゼロ）を確認したため、期待結果は満たしていると判定した。
- `pnpm lint` 実行時に Biome の informational な設定移行案内（`biome migrate`）が2件出るが、exit 0 でありエラーではない（TC-009 参照）。
