## 備考

- `dist/server/index.js` のサイズ 734.64 kB は testing.md 記載の HEAD 実測値 735.68 kB より 1.04 kB 小さい。testing.md の期待結果本文は「ビルドが成功し `apps/web/dist/server/index.js` が生成される」であり、サイズは括弧内の参考値。差分は testing.md 執筆時点（HEAD）以降の本ブランチ側コミット（レビュー反映の `fix:` / JSDoc 整理）に由来する減少と考えられ、撤去漏れを示す兆候（削除済み依存の解決エラー）は0件のため PASS と判定した。
- ビルド中に TanStack の非推奨警告が4件出る（`createServerFn().inputValidator() is deprecated. Use createServerFn().validator() instead.` — `LoginForm/action.ts:7` / `SignupForm/action.ts:7`）。本 Issue の変更とは無関係な既存の警告で exit 0 には影響しない。
