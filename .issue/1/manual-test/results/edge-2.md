# 異常系-2: 弱いパスワード（7文字）でエラーになり、8文字なら登録できる

**結果**: PASS
**対応する受け入れ基準**: AC-12（manual TC-34）
**実行時間**: 約40秒（※ブラウザセッションの入力イベント不達による再実行を除く）

## 補足

- 129文字以上を弾く上限側は本ケースの対象外（異常系-8）。
- 本ケースで **`boundary1@example.com` / `abcd1234`** のユーザーを作成した。
- 実行中に agent-browser のセッションが入力イベント（マウス・キーボード）を配送しなくなる事象が発生し、submit が発火せずエラーも POST も観測されない状態になった。セッションを閉じて開き直した後は正常。上表はセッション再作成後のクリーンな再実行結果。
